# Exploration：探索审计

更新日期：2026-10-02。来源：S1–S3及当前 be4160d 静态核查；[证据与修正](README.md#corrections)。

## 1. 入口与依赖

- [script_task.py](../../tasks/Exploration/script_task.py)使用 [solo.py](../../tasks/Exploration/solo.py)的任务实现。
- [base.py](../../tasks/Exploration/base.py)包含场景、章节、UP 关联、联动和战斗入口。
- [config.py](../../tasks/Exploration/config.py)、[assets.py](../../tasks/Exploration/assets.py)定义配置和资源。
- 战斗与奖励依赖 [Component/GeneralBattle/general_battle.py](../../tasks/Component/GeneralBattle/general_battle.py)。

## 2. 当前流程

```text
识别场景 → 等待必要过渡帧 → 必要时导航/前处理
  → 单人/队长/队员模式
  → 大世界选择章节 → 章节入口 → 探索地图
  → 检查结束/资源条件 → 宝箱、小纸人、BOSS等处理
  → 关联UP和攻击图标 → 点击目标 → 战斗/结算
  → 寻找下一目标或滑动 → 地图退出 → 收尾/后续排程
```

准备或战斗页面可进入接管路径。不能笼统写成“准备态无法接管”：S2 已修正 S1 的绝对结论，部分准备页也能通过 is_in_battle 的综合判据命中。仅准备模板成立而其他判据均不成立的边界仍需验证。

## 3. 已有能力保留

| 能力 | 主要依据 | 保留理由 |
|---|---|---|
| 当前场景接管 | solo.run、get_current_scene | 避免已经在探索仍完整导航 |
| 章节文字/最高章节/慢加载处理 | find_max_chapter、click_level_with_enhanced_ocr、open_expect_level | 外部不能完整替代当前容错 |
| 过渡页二次判断 | get_current_scene | 防短暂空帧误判 |
| UP 窄 ROI、中心点和横向加权 | search_up_fight | 适应当前按钮与图标布局 |
| 地图末端动画稳定判断 | run_solo | 不因一帧变化提前退出 |
| 退出补领奖励 | quit_explore | 保证退出前收尾 |
| 通用安全结算 | fire 调用 GeneralBattle | 保留禁点区域和点击冷却 |

## 4. 问题清单

| ID | 优先级 | 当前事实/风险 | 最小方向 |
|---|---|---|---|

| EX-03 | P0 | AP 不足抛通用 Exception，根执行器通用异常可退出实例 | 业务结束、有限清理和延期，不能无限重试资源耗尽 |

未知页、队伍初始化和退出等具体循环还应核查硬总期限。可重置的“无进展计时”不能代替总时间预算。

## 5. 目标选择与智能化边界

当前配置有 ALL、EXP、COIN、DARUMAA 等 UP 类型。search_up_fight 的 `(横向差×3)+纵向差` 排序用于关联 UP 与攻击按钮，不能称为目标收益或距离成本评分。

当前只有一个 I_UP_DARUMA，是达摩图案的 UP 加成标记，使用特征匹配。没有已证实的白/红/黑达摩分类、特殊奖励身份或完整稀有度评分。

后续顺序应为：

1. 页面确认和识别可信度。
2. 用户选择的可见类型硬过滤。
3. UP 与攻击按钮有效关联。
4. 可靠可见标签的简单优先规则。
5. 有真实数据后才加入移动与已知资源成本。

战后奖励可以用于统计和评估，不能据此声称战前看到了不可见目标身份。

## 6. 自动战斗与结束判断

小怪计数、时间限制和绘卷模式联动都可能结束探索。先明确当前计数是流程次数还是业务完成次数，再适配 GeneralBattle 返回结果；不能直接改成“胜利才加一”导致旧配置含义变化。

点击失败、地图过渡、异常弹窗、准备页、真实战斗应分别有证据。结算未完成不应被计为目标已完成，正常退出也不能形成错误档案。

独立 Exploration 与 MultiDaily 的子任务结束语义可能不同，结果适配须验证两种调用环境。资源耗尽是正常业务条件，仍需安排下一次时刻和正确返回页面。

## 7. 外部参考与低开销方向

| 来源/设计 | 可借鉴 | 保留边界 |
|---|---|---|
| yys 无关联目标返回 None | 防指定 UP 自动降级 | 不整体迁移其宽 ROI 和距离算法 |
| yys 突破券 total==30 | 业务数字校验 | 容量须按实际版本验证，不搬固定阈值/冷却 |
| 官方 dev 当前页优先和条件组合 | 限定候选、明确转换 | 保留当前遮挡/庭院/登录处理 |
| 当前同帧复用、变化日志 | 减少重复截图和日志 | 点击、页面/账号/资源变化后失效 |

三方默认截图间隔相近，没有同设备基准支持“某个版本一定更快”。先记录截图、OCR、模板匹配、等待、重试和阶段耗时，不全局删除 sleep。
